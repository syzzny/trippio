# 이미지 넣는 곳

Figma 파일의 **Trippio** 페이지에서 아래 두 프레임 안의 이미지를 내보내 이 폴더에 넣어주세요.

- `3D Assets` 프레임 → `3d-*.jpg` (18장)
- `Place Images` 프레임 → `dest-*.jpg`, `place-*.jpg` (16장)

각 이미지에 파일 이름과 JPG 3x 내보내기 설정이 미리 되어 있어요.
두 프레임을 선택한 뒤 오른쪽 패널 하단 **Export** → `Export N layers`를 누르면 한 번에 저장돼요.

이미지가 없어도 화면은 부드러운 그라데이션으로 대체돼 정상 동작해요.
(국내 여행지 중 부산·강릉·경주 이미지는 아직 없어서 그라데이션으로 보여요.)
